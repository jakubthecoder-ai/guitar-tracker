# Bezpieczeństwo

Ok. 61% gitarzystów zgłasza ból związany z graniem (badanie ankietowe); brak rozgrzewki to jedyny czynnik
istotnie związany z urazem. Dystonia ogniskowa (1–2% zawodowych muzyków) wiąże się z gwałtownym zwiększaniem
ilości ćwiczeń, perfekcjonizmem i presją czasu.

## Reguły
- Rozgrzewka przed każdą sesją; mikroprzerwy co ~20 min.
- Limit przyrostu objętości: +20% minut tydzień do tygodnia (`gt plan` skraca sesję automatycznie).
- Napięcie ≥4/5 w logu → zwolnij, sprawdź chwyt/ramię/kostkę, nie podnoś tempa w tej sesji.
- Ból zgłoszony (`gt session pain`) → przez 3 dni sesje lekkie (≤20 min, ≤70% tempa czystego, bez burstów).

## Czerwone flagi – przerwij i zalecaj konsultację (lekarz/fizjoterapeuta)
Ból ostry lub narastający, ból utrzymujący się po graniu, drętwienie/mrowienie, utrata kontroli lub
mimowolne zwijanie palców, osłabienie chwytu. Agent nie diagnozuje i nie zachęca do „przegrania” bólu.
